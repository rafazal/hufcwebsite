## ⚽ Heroes United FC Website

The official website for **Heroes United FC**, a nonprofit soccer program that provides inclusive playing opportunities for individuals with Down syndrome and other developmental disabilities.

The site serves as an informational hub for players, families, volunteers, and organizers, featuring program details, event information, and clear calls to action. It was built with a focus on **simplicity, accessibility, and ease of navigation** to ensure it’s usable by a wide range of users.

### Tech Stack

* HTML
* CSS
* JavaScript

### How It Works

* Static pages present program mission, events, and involvement opportunities
* Responsive layouts ensure the site works across desktop and mobile devices
* Clean, readable design prioritizes accessibility and clarity

This project supports a real nonprofit organization and demonstrates practical front-end development applied to a community-focused cause.
